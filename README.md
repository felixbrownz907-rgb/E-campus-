# E-Campus

An online learning management platform designed to connect students, lecturers, and administrators in one system.

## Features

- Student registration and applications
- Student dashboard
- Course management
- Module and lesson management
- Assignments
- Academic records
- Student profiles
- Administrator dashboard
- Enrollment management

## Technologies

- HTML
- CSS
- JavaScript
- Supabase
- PostgreSQL

## Project Purpose

E-Campus is being developed as a practical digital learning platform for managing academic activities and improving the learning experience for students and administrators.
